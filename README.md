# 🎲 Sorteador de Números

Um aplicativo web moderno e responsivo para gerar números aleatórios únicos em um intervalo específico.

## ✨ Características

- **Sorteio de números únicos** - Gera números aleatórios sem repetição dentro de um intervalo definido
- **Validações inteligentes** - Verifica valores inválidos e quantidade máxima de números disponíveis
- **Tema Dark/Light** - Alterne entre modo claro e escuro com preferência salva
- **Controle de fonte** - Aumentar/diminuir tamanho da fonte (12px a 24px) para melhor acessibilidade
- **Layout responsivo** - Funciona perfeitamente em desktop e mobile
- **Resultado em grade** - Números exibidos em cards coloridos com animação
- **Cópia rápida** - Copie os números sorteados com um clique
- **Efeitos sonoros** - Feedback sonoro ao realizar o sorteio
- **Persistência local** - Preferências de tema e tamanho de fonte são salvos

## 🚀 Como Usar

1. Abra o arquivo `sorteador.html` no navegador
2. Defina o número inicial e final do intervalo
3. Digite a quantidade de números a sortear
4. Clique em "Sortear Números"
5. Os números aparecem em uma grade colorida
6. Clique em "Copiar" para copiar para a área de transferência

## 🛠️ Tecnologias

- HTML5
- CSS3 (com suporte a dark mode)
- JavaScript vanilla (sem dependências)
- LocalStorage para persistência

## 📱 Compatibilidade

- ✅ Desktop (Chrome, Firefox, Safari, Edge)
- ✅ Mobile (iOS Safari, Chrome Mobile)
- ✅ Tablet

## 📦 Instalação

Nenhuma instalação necessária! É um arquivo HTML estático puro que pode ser:
- Aberto diretamente no navegador
- Servido em qualquer servidor web estático
- Deployado em Netlify, Vercel, GitHub Pages, etc.

## 💡 Exemplos de Uso

### Sorteio simples
- Intervalo: 1 a 100
- Quantidade: 10 números

### Sorteio de prêmios
- Intervalo: 1 a 50 (número de participantes)
- Quantidade: 5 (vencedores)

### Gerador de senhas numéricas
- Intervalo: 0 a 9999
- Quantidade: 1
